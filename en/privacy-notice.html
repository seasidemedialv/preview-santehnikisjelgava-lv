Privacy notice

This page describes what happens to the data you enter in the request form on santehnikisjelgava.lv.

The controller is the provider of the santehnikisjelgava.lv service.

What we receive from the form

The fields entered in the form: name, phone number, district, address (if you give it), type of problem, urgency and description. With them are sent the name of the page the request comes from, the time it was sent and a technical request number, so that one request is not received twice.

The site collects no other data about a visit: there are no analytics tools, ad pixels or cookies.

What the data is used for

Only to contact you about the job you requested and to carry it out. Once the form is sent, we contact you within 5 minutes. We do not sell the data or use it for advertising.

Where the data goes

  • The site’s hosting service (Cloudflare) keeps a copy of the request so that it is not lost because of a connection failure; the copy is deleted automatically after 90 days.
  • The request handling tool (Activepieces) passes it to the specialist in a message and writes the request into a table.
  • A WhatsApp message saying the request has been received is sent to the phone number you gave.

These service providers process the data only for this purpose.

How long the data is kept

The copy of the request in the site’s storage: 90 days. In the request table and in messages: as long as needed to carry out the job and for possible questions about it, unless you ask for deletion sooner.

Your rights

You have the right to find out what data about you has been received, to ask for it to be corrected or deleted, and to object to its processing. You can send the request through the same form: write what you want in the “Problem Description” field. You can also file a complaint with the Data State Inspectorate (dvi.gov.lv).

Fonts and external resources

Fonts and images are loaded from this same site, not from third-party servers, so during a visit your IP address is not passed to font or image services.

Changes

If this notice changes, the new version is published on this page. Updated 20 November 2026.
